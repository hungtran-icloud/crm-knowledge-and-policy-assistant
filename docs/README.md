## Cách sử dụng
1. Review nội dung cùng Project Manager, Tech Lead, Policy Owners và Privacy/Security Owner.
2. Thay các mục TBD/proposed bằng quyết định đã được phê duyệt.
3. Giữ requirement IDs và liên kết chúng với Jira Issues, test cases, PRs và Release Gates.
4. Không đưa dữ liệu khách hàng hoặc policy nội bộ hạn chế vào repository nếu chưa được cấp quyền.
